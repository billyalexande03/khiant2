CETAKFLOW - SETUP WINDOWS

SERVER:
1. Install Node.js LTS dari https://nodejs.org/
2. Extract folder CetakFlow.
3. Jalankan INSTALL_SERVER.bat sebagai Administrator.
4. Jalankan START_SERVER.bat.
5. Buka http://localhost:3000 di PC server.

CLIENT:
1. Hubungkan ke jaringan LAN/Wi-Fi yang sama.
2. Buka http://IP-SERVER:3000 di Chrome/Edge.

LOGO K2:
Logo K2 sudah dipasang sebagai logo aplikasi dan favicon.

BACKUP:
Jalankan BACKUP_DATA.bat secara berkala untuk membuat salinan database.
