CETAKFLOW K2 - WINDOWS

1. EXTRACT ZIP ini terlebih dahulu. Jangan jalankan BAT langsung dari dalam ZIP.
2. Pastikan Node.js LTS sudah terinstall: https://nodejs.org/
3. Jalankan INSTALL_SERVER.bat dengan double-click.
4. Jika Windows meminta izin, pilih Yes.
5. Setelah instalasi berhasil, jalankan START_SERVER.bat.
6. Di komputer server buka http://localhost:3000
7. Untuk komputer lain, gunakan http://IP-SERVER:3000

Jika INSTALL_SERVER.bat masih menutup sendiri, buka CMD secara manual,
masuk ke folder CetakFlow, lalu jalankan:
INSTALL_SERVER.bat
Dengan cara ini pesan error akan terlihat.
